# Исправление соотношения сторон карточек benefits

## Проблема
В CSS карточки `.benefit-grid-card` имеют:
- Фиксированную высоту `height: 200px` на изображениях
- `object-fit: cover` — обрезает изображения для заполнения фиксированной высоты
- `overflow: hidden` — скрывает выступающее содержимое

Это меняет визуальное соотношение сторон и обрезает карточки.

## Решение

### Файл: `style.css`

1. **Убрать фиксированную высоту и object-fit** (строки 522-527 и 535-540 — дубликаты):
   ```css
   /* БЫЛО: */
   .benefits .benefit-grid-card img {
       width: 100%;
       height: 200px;
       object-fit: cover;
       display: block;
   }

   /* СТАЛО: */
   .benefits .benefit-grid-card img {
       width: 100%;
       display: block;
   }
   ```

2. **Убрать overflow: hidden** (строки 516-520 и 529-533 — дубликаты):
   ```css
   /* БЫЛО: */
   .benefits .benefit-grid-card {
       flex: 1 1 0;
       min-width: 0;
       overflow: hidden;
   }

   /* СТАЛО: */
   .benefits .benefit-grid-card {
       flex: 1 1 0;
       min-width: 0;
   }
   ```

3. **Убрать дублирование** — удалить повторяющиеся селекторы `.benefit-grid-card` и `.benefit-grid-card img` (строки 529-540).

## Верификация
- Открыть страницу в браузере, прокрутить до секции "Дизайн в деталях"
- Проверить, что изображения отображаются без обрезки, с оригинальным соотношением сторон
- Проверить, что карточки выглядят аккуратно и не ломают сетку
