# План: выровнять карточки features по размеру

## Проблема
5 карточек в `.features-grid` могут иметь разную визуальную высоту из-за разного количества текста в описаниях. Также есть мёртвый CSS-код.

## Анализ текущего CSS (`style.css:405-443`)

**Текущий `.features-grid`:**
- `display: flex` — по умолчанию `align-items: stretch`, карточки УЖЕ должны быть одинаковой высоты
- Нет `flex-wrap` — все 5 карт в одну строку

**Текущий `.features-block`:**
- `width: 30%` — конфликтует с `flex: 1` (flex-grow перекрывает width)
- `justify-content: center` и `align-items: center` — **не работают** без `display: flex` на самом элементе

## Изменения в `style.css`

### 1. Убрать конфликт `width: 30%` из `.features-block` (строка 430)
`flex: 1` уже делит пространство поровну — `width: 30%` избыточен и может мешать.

### 2. Перенести `justify-content` / `align-items` в правильный контекст
- **Убрать** `justify-content: center` и `align-items: center` из `.features-block` (строки 432-433) — они бесполезны без `display: flex`
- **Добавить** `align-items: stretch` в `.features-grid` (явно, хотя и по умолчанию) для гарантии одинаковой высоты

### 3. Добавить `display: flex; flex-direction: column` в `.features-block`
Чтобы внутренние элементы (заголовок + параграф) располагались вертикально.

### 4. Добавить `flex: 1` для `p` внутри `.features-block`
Чтобы параграф растягивался и занимал оставшееся пространство — это выровняет визуальную высоту карточек.

## Итоговый CSS для `.features-grid` и `.features-block`

```css
.features-grid {
    display: flex;
    align-items: stretch;
    padding-top: 50px;
    gap: 25px;
}

.features-block {
    display: flex;
    flex-direction: column;
    background-color: var(--block-bg);
    padding: 20px 24px;
    flex: 1;
}

.features-block p {
    width: 90%;
    font-size: 16px;
    line-height: 1.3;
    padding-top: 10px;
    flex: 1;
}
```

## Дополнительное исправление (неравная ширина)

### Проблема
Flex-элементы по умолчанию имеют `min-width: auto` — не сжимаются меньше контента. Заголовки разной длины создают разный минимальный размер.

### Решение
Добавить `min-width: 0` в `.features-block`.
