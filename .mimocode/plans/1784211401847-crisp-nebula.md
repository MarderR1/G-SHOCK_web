# Benefits: 4 карточки в один ряд, одинаковые картинки

## Ситуация

Сейчас у `.benefit-grid-card` и `img` внутри них нет CSS-правил. Картинки отображаются в оригинальном размере, карточки разного размера.

## Что нужно

4 карточки **в один ряд**, все одинакового размера, картинки одинаковые.

## Изменения

**Файл:** `style.css`, добавить после `.benefits .benefits-grid` (после строки 514):

```css
.benefits .benefit-grid-card {
    flex: 1 1 0;
    min-width: 0;
    overflow: hidden;
}

.benefits .benefit-grid-card img {
    width: 100%;
    height: 200px;
    object-fit: cover;
    display: block;
}
```

### Что делает:

- `flex: 1 1 0` — все 4 карточки делят пространство поровну, `min-width: 0` не даёт им распирать контейнер
- `img { width: 100%; height: 200px; object-fit: cover }` — все картинки одинакового размера, без искажений

## Верификация

1. Открыть `index.html` в браузере
2. Все 4 карточки в одну строку, одинакового размера
3. Картинки одинаковые, не искажены
